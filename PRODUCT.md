# C23 Experience Cloud Bundle – Product Notes

## What this bundle solves
- Discovery: users can find Cases/Orders/Assets/Knowledge fast and in one place
- Deflection: Knowledge Explorer UX reduces case volume
- Conversion/engagement: targeted hero/cta/announcements drive the next action

## “Premium tier included” guidance
Build the AI Summary UX into Knowledge Explorer Pro by default (no tier gating).
Implementation may start with an Apex provider abstraction so the org can plug in:
- Salesforce native AI (if available)
- External LLM via Named Credential (optional)
