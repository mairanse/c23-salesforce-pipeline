# Permission Studio – Product Notes (Dev Org)

## What we’re building now
A “User Permission Summary” experience that makes it obvious:
- what a user has,
- where it comes from (profile vs assigned perm set vs group),
- and how users differ (compare up to 4).

## What “good” looks like
- Fast: search, select, results within ~1 second in a typical org.
- Clear hierarchy: minimal wasted vertical space; content-first layout.
- Useful insights: show what’s common/unique/missing without mental math.

## Near-term feature ideas (agent may propose/implement after Phase 3)
- Export comparison to CSV
- “Explain why” a permission is granted (source tracing)
- Expand PSG into component permission sets (toggle)
- Show system permission deltas (later)
- Show object CRUD summary deltas (later)
- Save comparison sets (recent comparisons)
